# Genre Guide — Action Adventure

## Fantasía
Exploración, combate action, puzzles, story beats.

## Sistemas comunes
- Traversal + combat hybrid
- Checkpoint / rest systems
- Lock & key / ability gating
- Cinematics / dialogue ligero
- Map / journal

## Arquitectura
- Zonas streaming
- Ability flags en save
- Camera modes (explore vs fight)
- Combat hitboxes data-driven

## Riesgos
- Soft-lock por ability gating mal testeado
- Camera en espacios mixtos
- Story scope vs gameplay

## Planning checklist
- [ ] Ability gate graph documentado
- [ ] Soft-lock QA pass
- [ ] Combat sandbox
- [ ] Save en boundaries de zona
