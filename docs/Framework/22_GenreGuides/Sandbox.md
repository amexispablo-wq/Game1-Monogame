# Genre Guide — Sandbox

## Fantasía
Libertad de herramientas, construcción, física juguete, UGC.

## Sistemas comunes
- Tool / interaction framework
- Building / voxel / props
- Serialization de mundos grandes
- Permissions (creative vs survival)
- Workshop/mod pipeline fuerte

## Arquitectura
- Content packs por ID
- Undo stacks en build tools
- Perf: pooling + culling
- Cloud/local world slots

## Riesgos
- Perf death by player creativity
- Formatos de mundo imposibles de migrar
- Moderación UGC

## Planning checklist
- [ ] Tool API extensible
- [ ] World save version
- [ ] Perf budget con “max build”
- [ ] UGC policy
